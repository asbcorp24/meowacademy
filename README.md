# 🐱 МяуАкадемия

PHP + SQLite прототип тренажёра кошачьего мяуканья.

## Запуск

Нужны PHP 8.3+, расширения `pdo_sqlite`, `fileinfo`, `mbstring` и современный браузер.

```bash
export MEOW_ADMIN_PASSWORD='replace-with-a-long-random-password'
php -S localhost:8000 -t public public/index.php
```

Откройте http://localhost:8000. Админка: `/login` → `/admin`. Для записи микрофона на удалённом сервере требуется HTTPS (localhost — исключение).

## Что реализовано

- SQLite со схемой уроков и попыток, автоматическое создание базы;
- админ-вход по паролю из окружения, CSRF-защита форм;
- загрузка MP3/WAV/OGG до 12 МБ и каталог уроков;
- запись с микрофона и прослушивание;
- анализ RMS-огибающей, отсечение тишины, нормализация, DTW и сравнение длительности;
- график эталона и ученика, подсветка отличий, базовые советы и сохранение оценки.

## Ограничения прототипа

Сейчас **не реализованы** выделение F0, форманты, спектральный анализ и достоверное сравнение тембра. Оценка — учебная эвристика, не измерение качества «кошачьего произношения». `features` пока хранит пустой JSON, автоматической обработки эталона при загрузке нет. Для публичного развёртывания необходимы ограничение частоты запросов, авторизация учеников и усиление защиты API. Серверная SQLite и файлы должны оставаться за пределами web root.
