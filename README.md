# 🐱 МяуАкадемия

PHP + SQLite прототип тренажёра кошачьего мяуканья.

## Запуск

Нужны PHP 8.3+, расширения `pdo_sqlite`, `fileinfo`, `mbstring` и современный браузер.

```bash
php -S localhost:8000 -t public public/index.php
```

Откройте http://localhost:8000. Админка: `/login` → `/admin`. Для записи микрофона на удалённом сервере требуется HTTPS (localhost — исключение).

### Пароль администратора

Скопируйте `storage/admin_password.txt.example` в `storage/admin_password.txt`, затем замените содержимое файла своим паролем длиной не менее 12 символов. В файле должна быть **одна строка** с паролем, без кавычек. PHP должен иметь право читать файл.

```bash
cp storage/admin_password.txt.example storage/admin_password.txt
nano storage/admin_password.txt
chmod 640 storage/admin_password.txt
```

Для Apache с пользователем `www-data` выдайте файлу подходящие владельца/группу (например, `chown deploy:www-data storage/admin_password.txt`). Файл исключён из Git. Никогда не размещайте его в `public` и не публикуйте в репозитории.

## Что реализовано

- SQLite со схемой уроков и попыток, автоматическое создание базы;
- админ-вход по паролю из окружения, CSRF-защита форм;
- загрузка MP3/WAV/OGG до 12 МБ и каталог уроков;
- запись с микрофона и прослушивание;
- анализ RMS-огибающей, отсечение тишины, нормализация, DTW и сравнение длительности;
- график эталона и ученика, подсветка отличий, базовые советы и сохранение оценки.

## Ограничения прототипа

Сейчас **не реализованы** выделение F0, форманты, спектральный анализ и достоверное сравнение тембра. Оценка — учебная эвристика, не измерение качества «кошачьего произношения». `features` пока хранит пустой JSON, автоматической обработки эталона при загрузке нет. Для публичного развёртывания необходимы ограничение частоты запросов, авторизация учеников и усиление защиты API. Серверная SQLite и файлы должны оставаться за пределами web root.

## Акустический анализ v2

При загрузке эталона браузер автоматически декодирует запись, рассчитывает кадры FFT (2048 отсчётов, шаг 512), RMS, оценку F0 через разностную функцию, спектральный центроид, плоскостность и три сильнейших спектральных пика. Признаки сохраняются как JSON в SQLite вместе с уроком. Тренажёр анализирует запись пользователя и сравнивает длительность, высоту тона, относительную интонацию, громкость и грубые спектральные характеристики. График показывает огибающие, проблемные участки отмечаются цветом.

**Ограничения:** спектральные пики не равны надёжно измеренным формантам (для них нужен LPC/специализированная модель); высота тона может ошибаться на шумном и многоголосном звуке, включая кошачье мяуканье. Временная нормализация здесь линейная, полноценное DTW по многомерным признакам ещё не внедрено. Проценты являются эвристикой, а не научно валидированной оценкой. Предобработка эталонов происходит в браузере администратора, не на PHP-сервере. Не загружайте очень длинные записи: обработка выполняется в основном потоке браузера.
